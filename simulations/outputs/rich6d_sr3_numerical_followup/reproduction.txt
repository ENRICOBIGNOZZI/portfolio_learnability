TARGETED FOLLOW-UP: REPRODUCTION AND SCOPE

This directory supplements rich6d_rough_sr3_extended_v2. It does not replace
the original 300-path production experiment or its figures. Baseline economic
parameters, annualized optimal Sharpe 3, Matérn kernel, and prescribed penalty
constant are unchanged. The twelve original independent pilot indices are
reused for a paired numerical comparison at four long training horizons.

Use the repository's simulations/requirements.txt and Python 3.13. For the
original bitwise economic-history checks, use macOS as in the reference run.
Set OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1, VECLIB_MAXIMUM_THREADS=1, and
PYTHONDONTWRITEBYTECODE=1. Run all commands from the repository root.

1. Recompute the complete 300-path diagnostic penalty comparisons:
   python3 -m simulations.extended.followup_diagnostics

2. Recompute the higher-rank population moments and independent evaluation:
   python3 -m simulations.extended.rank_followup population --rank 8192
   Large Cholesky caches are regenerable and live outside the repository in
   /tmp/rich6d_rank_followup_cache. The small saved population policy
   coefficients and their numerical checks are retained here.

3. The twelve fitted policy artifacts are included in fits/. To regenerate
   a missing fit locally, run the following for each index 0 through 11:
   python3 -m simulations.extended.rank_followup fit --rank 8192 --index INDEX
   Existing fits are checkpointed. Remote execution used the standard
   macos-26 workflow rich6d-rank-followup.yml with four concurrent jobs.
   The exact successful run and source commit are in remote_fit_receipts.json.

4. Independently evaluate every saved pair, using common characteristic
   quadrature and analytical integration over factors and idiosyncratic noise:
   python3 -m simulations.extended.rank_followup evaluate
   This step reproduces all original lower-rank policy population metrics.

5. Recompute the rank/quadrature gates, paired slope changes, and report:
   python3 -m simulations.extended.followup_report

6. Run the focused correctness tests:
   python3 -m pytest -q tests/test_rank_followup.py

The ex-post oracle maximizes mean Sharpe across the fixed 96-penalty grid;
it does not maximize separately within each replication. Even/odd cross-fitting
checks selection optimism using independent evaluation indices, but remains a
population-information diagnostic. No reported strategy or constant a is
retuned. Oracle slope intervals are deliberately omitted because shared
selection folds induce cross-path dependence; fixed-index paired errors are
explicitly conditional diagnostics.

The original 5% regret-based acceptance threshold is retained. The highest
rank has no higher-rank certificate. Read critical_followup_report.txt and
verification.json for actual passes and failures; computation completion
does not imply numerical resolution. Changes to N or rho are not rerun here.
