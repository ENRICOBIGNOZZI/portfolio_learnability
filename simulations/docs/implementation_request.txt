2. FINAL BASELINE DGP
============================================================

Implement the new DGP from first principles.

There are N stocks and K_F = 3 economic factors.

For stock i:

    R_{i,t+1}
      = beta(Z_{i,t})' F_{t+1}
        + epsilon_{i,t+1}.

Write in matrix form:

    R_{t+1} = B_t F_{t+1} + epsilon_{t+1},

where row i of B_t is beta(Z_{i,t})'.

--------------------------------
2.1 Characteristics
--------------------------------

Start from persistent latent Gaussian characteristics.

For each primitive characteristic coordinate d,

    S_{i,d,t+1}
      = rho_d S_{i,d,t}
        + sqrt(1-rho_d^2) eta_{i,d,t+1},

with

    eta_{i,d,t+1} ~ N(0,1),

and stationary initialization

    S_{i,d,0} ~ N(0,1).

Use fixed persistence parameters rho_d satisfying |rho_d|<1.

Transform latent Gaussian states to population ranks:

    U_{i,d,t} = Phi(S_{i,d,t}),

or the equivalent [-1,1] normalization

    Z_{i,d,t} = 2 Phi(S_{i,d,t}) - 1.

IMPORTANT:
The theoretical baseline must use the POPULATION probability integral
transform, not an empirical cross-sectional rank transform, because the
population support must remain continuous.

An empirical rank transform may be implemented only as a separate
robustness experiment.

--------------------------------
2.2 Factor loadings
--------------------------------

Use a smooth nonlinear beta mapping with constant norm:

    || beta(z) ||^2 = c_beta.

Use the canonical smooth construction from the final DGP specification.
A convenient implementation is a smooth angular representation such as

    beta(z)
      = sqrt(c_beta) *
        (
          sqrt(2/3) cos(2 pi u(z)),
          sqrt(2/3) sin(2 pi u(z)),
          1/sqrt(3)
        )',

where u(z) is the designated smooth scalar characteristic index.

This ensures

    ||beta(z)||^2 = c_beta

for every z.

The implementation must ALSO enforce the exact cross-sectional balance

    (1/N) B_t' B_t = Gamma_beta

at every t,

with baseline

    Gamma_beta = (c_beta/3) I_3.

Use the balanced-triplet construction from the final DGP specification,
or an algebraically equivalent construction.

This identity must hold numerically to machine precision.

It is not an approximate large-N result.
It is a defining property of the baseline DGP.

--------------------------------
2.3 Factors
--------------------------------

Normalize the factor second moment:

    E[F_{t+1} F_{t+1}' | F_t-info] = I_3.

Use

    E[F_{t+1} | F_t-info] = mu_F.

For the Gaussian baseline generate

    F_{t+1}
      ~ N(mu_F, I_3 - mu_F mu_F'),

requiring

    ||mu_F||^2 < 1.

Verify numerically that

    E[F F'] = I_3

under a long population simulation.

Do NOT reinterpret I_3 as the covariance.
It is the SECOND MOMENT.

The covariance is

    Var(F) = I_3 - mu_F mu_F'.

--------------------------------
2.4 Idiosyncratic shocks
--------------------------------

Use

    epsilon_{t+1}
      ~ N(0, sigma_epsilon^2 I_N),

conditionally independent of factor innovations.

Do not project residuals into any artificial orthogonal complement.

Do not manipulate epsilon to force managed factors to become exactly
orthogonal.

This must be an ordinary factor model with genuine idiosyncratic risk.

============================================================
3. POPULATION OPTIMAL PORTFOLIO
============================================================

Do NOT impose W*(z).

Derive it from the population loss.

The paper uses

    R^p_{t+1}(W)
      = (1/N) sum_i W(Z_{i,t}) R_{i,t+1}

and

    Q(W)
      = E[(1 - R^p_{t+1}(W))^2].

Under the balanced DGP,

    m_t
      := E[R_{t+1} | F_t-info]
       = B_t mu_F,

and

    S_t
      := E[R_{t+1} R_{t+1}' | F_t-info]
       = B_t B_t'
         + sigma_epsilon^2 I_N.

The conditional normal equation is

    S_t w_t* = m_t.

Use

    (B B' + sigma^2 I)^{-1} B
      = B (B'B + sigma^2 I)^{-1}

and

    B_t' B_t / N = Gamma_beta

to derive

    w_t*
      = (1/N) B_t
        (Gamma_beta + sigma_epsilon^2/N I_3)^{-1}
        mu_F.

Therefore the POPULATION POLICY IS

    W*(z)
      = beta(z)'
        (Gamma_beta + sigma_epsilon^2/N I_3)^{-1}
        mu_F.

For the isotropic baseline

    Gamma_beta = c_beta/3 I_3,

so

    W*(z)
      =
      beta(z)' mu_F
      /
      (c_beta/3 + sigma_epsilon^2/N).

This formula must be DERIVED in documentation and checked numerically.

Do not substitute a different population target.

4. ASSUMPTION AUDIT E1–E6
============================================================

Produce both analytical checks and numerical diagnostics.

--------------------------------
E1 — dependence
--------------------------------

The latent Gaussian AR(1) state is stable.

Record:
- rho_d;
- spectral radius;
- stationarity initialization.

The simulation code should be compatible with geometric beta-mixing.

Do not attempt a large new formal proof unless needed.
Document that geometric beta-mixing implies the paper's polynomial
beta-mixing condition for every finite gamma and therefore for some
gamma>b.

--------------------------------
E2 — Gaussian-type managed-return tails
--------------------------------

The paper defines

    X_t
      = (1/N) sum_i R_{i,t+1} K(., Z_{i,t})

and therefore

    ||X_t||_H^2
      = N^{-2} R_{t+1}' K_t R_{t+1},

where

    (K_t)_{ij}
      = K(Z_{i,t}, Z_{j,t}).

The baseline must numerically and analytically support the condition

    E[
      exp(
        N^{-2} R_{t+1}' K_t R_{t+1}
        / B_X^2
      )
      | F_t-info
    ] <= 2.

For the conditional Gaussian DGP, use the exact non-central Gaussian
quadratic-form MGF wherever numerically feasible.

Audit:
- largest relevant covariance eigenvalue;
- selected B_X;
- exact/log-MGF value;
- maximum value across audited states.

Do not estimate this condition only by counting tail violations.
Use the exact Gaussian formula whenever possible.

The conditional fourth-moment condition must also be checked:

    E[
      (R^p_{t+1}(V))^4
      | F_t-info
    ]
    <=
    K_4
    {
      E[
        (R^p_{t+1}(V))^2
        | F_t-info
      ]
    }^2.

Since every admissible portfolio payoff is conditionally Gaussian,
the baseline satisfies

    K_4 = 3.

Verify this analytically and numerically on random admissible policies.

--------------------------------
E3 — W* in the Matérn RKHS
--------------------------------

The baseline has

    W*(z) = c' beta(z)

for a constant vector c.

Therefore if all beta_k belong to the Matérn RKHS,

    W* in H_K.

Use smooth beta functions.

Document their differentiability / Sobolev regularity and why it is
sufficient for the chosen Matérn kernel.

Do not merely state “beta is smooth”.
Write the actual beta functions and verify the required regularity.

--------------------------------
E4 — conditional pricing restriction
--------------------------------

This must be checked EXACTLY.

For every admissible V,

    E[
      (1 - R^p_{t+1}(W*))
      R^p_{t+1}(V)
      | F_t-info
    ] = 0.

Numerically verify the equivalent vector identity

    S_t w_t* = m_t

for many generated states.

Report

    max_t ||S_t w_t* - m_t||_2

and require machine-level error.

This is possible because the cross-sectional balance identity is exact.

--------------------------------
E5 — managed-payoff spectrum
--------------------------------

Use the Matérn kernel.

Define the kernel covariance/integral operator

    T_K = E[K_Z tensor K_Z].

For the managed feature covariance

    Sigma_H = E[X_t tensor X_t],

establish the operator comparison

    (sigma_epsilon^2/N) T_K
      <= Sigma_H
      <=
      (c_beta + sigma_epsilon^2/N) T_K

in the quadratic-form / Loewner sense.

This implies that Sigma_H and T_K have the same eigenvalue-decay
exponent.

For a Matérn kernel with smoothness nu on D-dimensional compact
characteristic support, use the relevant asymptotic eigenvalue law

    lambda_j(T_K)
      ~ j^{-b},

with

    b = 1 + 2 nu / D

under the regular setting used in the paper.

For the headline design choose parameters so that

    b = 3/2.

One convenient headline choice is

    nu = 3/2,
    D = 6.

IMPORTANT:
Do not impose mu_j = c j^{-b} in the DGP.
The spectrum must emerge from DGP + Matérn kernel.

Numerically:
- estimate a large population covariance;
- compute leading eigenvalues;
- plot log(mu_j) against log(j);
- fit slopes over several predeclared tail windows;
- report uncertainty / sensitivity to fitting window;
- compare with theoretical -b.

--------------------------------
E6 — non-degenerate Sharpe
--------------------------------

For the population optimal payoff compute

    q*
      = E[R^p(W*)]
      = E[(R^p(W*))^2]

under the normal equation.

Then

    SR*^2 = q* / (1 - q*).

Calibrate mu_F so that

    0 < q* < 1

and comfortably away from 0 and 1.

Use a realistic, non-degenerate Sharpe.
Do not choose the signal solely to make plots visually dramatic.

Report:
- q*;
- population mean;
- population variance;
- population Sharpe;
- long-run Monte Carlo counterparts.
