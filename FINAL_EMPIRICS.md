# Final empirical section

This file records the empirical design that matches the current paper. It also
marks which older figures must not be used in the main text.

## Core empirical message

The empirical section is organized around one mechanism:

more history -> less shrinkage -> more active portfolio directions,
while effective complexity relative to available history declines.

For the Gaussian representation the paper's fast-decay benchmark implies the
inverse-history schedule

\[
\lambda_T = \lambda_0 T_0 / T.
\]

There is no r parameter in this Gaussian experiment.

### B. Portfolio performance across representations

For the finite numerical implementations, use a common nominal nonlinear
feature dimension of 1,000 coordinates. Gaussian and Matérn use 1,000 random
Fourier features. The NTK uses 500 Monte Carlo hidden directions, each
contributing an NNGP/ReLU coordinate and a derivative coordinate, for exactly
1,000 final NTK feature coordinates. This makes the nominal-size comparison
across nonlinear representations like-for-like. The linear specification has
133 coordinates including the constant.

Changing NTK from 2,000 to 1,000 final coordinates invalidates the previously
saved NTK backtest, complexity curves, spectra, and Table-III NTK row. Rerun
the NTK pipeline before updating the manuscript.

### D. History, shrinkage, and effective complexity

This is the central empirical learnability figure.

Run:

python expanding_window_gaussian.py --characteristics all

The script calibrates lambda_0 once on the initial train/validation split and
then compares:

1. fixed initial lambda_0;
2. lambda_T = lambda_0 T_0 / T;
3. the original annual-validation rule as an appendix benchmark.

At every test year:

- T is the number of monthly observations in the full expanding refit sample;
- Sigma-hat_T is estimated from all observations before that year;
- C_T is computed from the eigenvalues of that expanding operator;
- the portfolio coefficients are refitted on the same expanding history.

Main figure:

Panel A: T -> lambda_T
Panel B: T -> C_T
Panel C: T -> C_T / T

For Panels B and C, show only the five-year centered moving average in the
main text. The exact raw annual series is saved and shown in the appendix.
The lambda schedules are exact and are not smoothed.

Main figure includes only fixed lambda and the inverse-history rule. Annual
validation is an appendix benchmark because its year-to-year tuning noise
obscures the economic mechanism.

Suggested caption:

"History, shrinkage, and learnable portfolio complexity. The Gaussian penalty
is calibrated once on the initial sample. The solid path applies the
inverse-history rule lambda_T = lambda_0 T_0/T; the dashed path holds the
initial penalty fixed. At every annual refit, the managed-payoff operator and
portfolio coefficients are re-estimated using all prior observations. The
middle and lower panels show five-year centered moving averages of the annual
effective-complexity estimates; unsmoothed values are reported in the
appendix. Declining shrinkage activates additional managed-portfolio
directions as history accumulates, while C_T/T measures complexity relative to
the amount of available return history."
